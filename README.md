# Resize Filesystem Image Tool

A powerful and safe Bash tool to **shrink filesystem images** to their minimum size with an optional margin.

This script performs:

- Shrinking to minimum size
- Smart truncation of the disk image
- Optional backup and output redirection
- Report generation (only JSON supported currently)

---

---

## Installation

Clone this repository:

```bash
git clone https://github.com/Robby-Djakou/fsimage_resize.git
cd fsimage_resize
sudo ./fsimage_resize -m 600M -r foo.json bar.img
```
